# Phantom Tower / 影塔·百战

Boss-rush mod for *Phantom Blade Zero* (影之刃零).

Download the latest release assets. See the [v1.0.0 release](https://github.com/Lassysi/Phantom-Tower/releases/tag/v1.0.0) for install notes.

This repository hosts release packages only. No open-source license is declared for the mod itself. Third-party MinHook license text is included inside `PBZTower-v1.0.0-mod.zip` as `THIRD-PARTY-LICENSES.txt` ([MinHook LICENSE](https://github.com/TsudaKageyu/minhook/blob/master/LICENSE.txt)).
