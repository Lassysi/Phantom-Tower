PHANTOM TOWER v{VERSION} — MANUAL INSTALLATION

IMPORTANT: Tower runs from 3.0.0 or later continue after updating. Runs from versions before 3.0.0 cannot be continued: start a new tower run. If you are still inside a tower run, choose Save and Exit in game first. Back up your old tower data (%LOCALAPPDATA%\PBZTower) and old mod files before updating. Your original game save is separate.

1. Close the game. Back up %LOCALAPPDATA%\PBZTower and your existing tower mod files.
2. If PBZ\platform\steam\avrt.dll belongs to another mod, do not overwrite it: the mods may conflict.
3. Copy the included platform folder into the PBZ game root (Steam\steamapps\common\PBZ), and merge the folders.
4. Check that PBZ\platform\steam\avrt.dll and PBZ\platform\steam\PBZTower\PBZTower.dll exist.
5. Start the game and load your normal save. Press Insert to open the tower. Gamepad: press L3 + R3 together. Use the language row to switch English / 中文.
6. The Nexus mod archive does not include a key-remapping tool. Use Insert or L3 + R3.

Update from 3.x: keep your tower data and replace this mod's platform files. Update from 2.x or older: start a new tower run; the original game save is separate.
Uninstall: close the game, then remove only this mod's avrt.dll and its PBZTower folder. Do not delete another mod's avrt.dll. Tower data remains in %LOCALAPPDATA%\PBZTower unless you remove it yourself.
See platform\steam\PBZTower\README.txt for the full bilingual guide. Single-player only.

影塔·百战 v{VERSION} — 手动安装

重要：3.0.0 及以后版本的爬塔局更新后可以直接继续；3.0.0 之前的爬塔局不能继续，需要开新局。若还在影塔里，请先在游戏中「保存并退出」。更新前请备份旧版 Mod 文件和影塔数据（%LOCALAPPDATA%\PBZTower）；游戏原存档与影塔局分开。

1. 关闭游戏。备份 %LOCALAPPDATA%\PBZTower 和当前影塔 Mod 文件。
2. 若 PBZ\platform\steam\avrt.dll 属于其他 Mod，不要直接覆盖，两者可能冲突。
3. 将压缩包中的 platform 文件夹复制到 PBZ 游戏根目录（Steam\steamapps\common\PBZ），合并文件夹。
4. 确认 PBZ\platform\steam\avrt.dll 和 PBZ\platform\steam\PBZTower\PBZTower.dll 存在。
5. 启动游戏并进入原存档，按 Insert 打开影塔；手柄同时按 L3 + R3。可在语言选项切换中文 / English。
6. N 网 Mod 压缩包不包含改键工具，请使用 Insert 或手柄 L3 + R3。

从 3.x 更新：保留影塔数据，覆盖本 Mod 的 platform 文件。从 2.x 及更早版本更新：需开始新的爬塔局；游戏原存档与影塔局分开。
卸载：关闭游戏后，仅删除本 Mod 的 avrt.dll 和 PBZTower 文件夹，不要删除其他 Mod 的同名文件。影塔数据留在 %LOCALAPPDATA%\PBZTower，可自行决定是否删除。
完整中英文玩法说明见 platform\steam\PBZTower\README.txt。仅限单人游戏。
