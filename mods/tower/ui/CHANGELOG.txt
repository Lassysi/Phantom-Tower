ABI 4 compatibility update — 2026-10-31
- Loader hello/module checks now require ABI 4; ABI 3 is rejected before loading.
- New packages require a matching frozen ABI 4 engine; the old ABI 3 release is retired.
- 加载器握手改为 ABI 4；正式打包须提供新冻结版本，拒绝旧 ABI 3。

0.2.0 — 2026-10-30
- Native bilingual loader with game discovery, pipe-owner validation, ABI 3 handshake,
  and compatible runtime/module reuse.
- Waits for initialization; injects at most once per process instance. No runtime
  unload, hot replacement or tower gameplay controls.
- Packages only a matching frozen Claude engine pair, as self-contained EXE and
  folder ZIP with SHA-256 checksums.
- The paused external-overlay prototype is excluded from this package.
- The frozen engine predates native-UI work. Loader acceptance is offline only;
  this is not a claim that the complete mod has been validated in the live game.
